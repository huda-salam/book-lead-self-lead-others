# Visual Editorial System v0.1

## Purpose
The site should feel like a serious practical leadership book, not a plain documentation site.
VitePress already provides a strong visual grammar for headings, sidebar, outline, code blocks, custom containers, and GitHub-style alerts. The book extends that grammar with a bright sky-blue identity.

## Semantic palette
| Mark | Meaning | Use |
|---|---|---|
| Info | Context / definition | Explain terms, scope, evidence |
| Tip | Practical technique | Actionable shortcut or practice |
| Important | Core principle | Principle that materially changes application |
| Caution | Misuse / trade-off | This can backfire |
| Warning | Meaningful risk | Organizational/interpersonal risk |
| Danger | Hard boundary | Serious safety, ethics, authority, or compliance boundary |
| Success / Green Note | Carry-forward synthesis | Keep this |
| Red Note | Anti-pattern / red flag | Stop and inspect |
| Details | Optional depth | Evidence, examples, extended discussion |

## Editorial rule
Color is a retrieval aid, not an evidence rating.
A green note does not mean true. A red note does not mean false.

## Recommended chapter rhythm
1. Opening proposition
2. Why this matters for a leader
3. Capability
4. Mechanism
5. Evidence / limits
6. Practical situations
7. Decision or response examples
8. Practice
9. Red flags / failure modes
10. Carry-forward synthesis

Use heading hierarchy and whitespace to make structure visible before adding callouts.

## Example syntax
::: success Green Note
**Leader mindset:** jangan hanya bertanya apa respons saya? Tanyakan juga apa yang sedang saya coba capai, siapa yang terdampak, dan apa konsekuensi setelah saya bertindak?
:::

::: danger Red Note
**Jangan menyamakan ketenangan dengan kepemimpinan.** Dalam situasi tertentu, keputusan cepat, penolakan, atau eskalasi justru diperlukan.
:::

::: warning Risiko
Bahasa yang lebih halus tidak otomatis membuat keputusan lebih adil atau masalah lebih kecil.
:::

::: details Baca Lebih Dalam
Masukkan bukti, batas penerapan, atau contoh tambahan yang berguna tetapi tidak harus dibaca oleh semua pembaca.
:::

## Anti-pattern visual
Avoid every paragraph inside a callout; red boxes for ordinary disagreement; green boxes for motivational slogans; excessive emoji; giant headings for minor sections; long tables when prose is clearer; and styling that makes evidence status ambiguous.
