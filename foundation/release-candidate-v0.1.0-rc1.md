## RC scope

This candidate is intended for **reader testing**, not as a claim that the manuscript is typo-free or empirically validated as a whole.

Reader testing should focus on whether the book is:

1. understandable without the author's oral explanation;
2. practically usable in real situations;
3. internally consistent;
4. sufficiently evidence-aware;
5. capable of changing how readers observe, decide, communicate, act, and review.

## Known conditions

- Book frameworks are working/book syntheses unless explicitly supported as established constructs.
- Examples are not automatically causal evidence.
- Contemporary exemplars require current source-backed case packets before additional claims are added.
- Public-site availability still requires an external browser smoke test.
- The project currently has no GitHub Release/tag created through the available repository tooling.
- `vitepress: latest` remains a reproducibility consideration for a future dependency-maintenance pass; it is not being mixed into the RC editorial change set.
