# Terminology Collision Matrix v0.2 — Memimpin Diri, Memimpin Sesama

> v0.2 adds discipline/consistency/persistence collisions to the canonical terminology QA layer.

| Cluster | Canonical owner | Distinction | Prohibited conflation | Retrieval routing |
|---|---|---|---|---|
| Discipline / consistency | SELF.DISCIPLINE + SELF.CONSISTENCY | discipline = capability/process; consistency = repeated behavioral pattern | discipline ≠ mere frequency; consistency ≠ rigidity | “tahu harus tetapi tidak menjalankan” → discipline; “berulang stabil” → consistency |
| Persistence / rigidity | SELF.RESILIENCE + SELF.PERSISTENCE | persistence continues a valid goal while allowing method change; rigidity repeats despite contrary evidence | persistence ≠ stubborn repetition | setback/continuation → resilience; “harus terus dengan cara ini” → rigidity/adaptation |
| Goal discipline / solution attachment | DECISION.GOAL_DISCIPLINE | goal discipline protects objective; solution attachment protects preferred method | commitment to a solution ≠ commitment to a goal | “saya sudah terlanjur memilih cara ini” → goal discipline |
| Discipline / motivation | SELF.DISCIPLINE | motivation is a fluctuating state; discipline concerns execution despite fluctuations | low motivation ≠ automatic inability to act; discipline ≠ permanent motivation | “semangat hilang” → discipline + practice design |
| Discipline / perfectionism | SELF.DISCIPLINE | discipline supports necessary standards; perfectionism can impose excessive/unworkable standards | strictness ≠ discipline | repeated over-control/avoidance → review standards and constraints |
| Literacy discipline / skepticism | LITERACY.DISCIPLINE | literacy discipline calibrates conclusions to evidence and uncertainty | skepticism ≠ cynicism; doubt ≠ evidence | “benarkah informasi ini?” → literacy discipline |
| Literacy discipline / over-analysis | LITERACY.DISCIPLINE | evidence checking must be proportional to decision stakes | endless checking ≠ rigor | high-stakes claim → stronger verification; low-stakes → proportional check |
| Persistence / goal validity | DECISION.GOAL_DISCIPLINE | persistence is appropriate only while the goal remains valid and worth pursuing under current constraints | stopping ≠ failure; continuing ≠ virtue by itself | “kapan berhenti?” → goal validity + evidence + reversibility |
| Consistency / adaptation | SELF.CONSISTENCY + STRAT.ADAPTATION | consistency can apply to principles/standards while methods change | consistency ≠ doing exactly the same thing | “tetap konsisten tetapi situasi berubah” → goal discipline + adaptation |
| Discipline / moral blame | SELF.DISCIPLINE | failure to execute is a signal for diagnosis, not proof of weak character | missed execution ≠ laziness/weakness as fact | execution failure → diagnose trigger, friction, commitment, method, context |

## Retrieval QA additions

1. “Saya semangat sekali di awal, lalu lemas di tengah.” → SELF.DISCIPLINE + SELF.CONSISTENCY + PRACTICE.OS.
2. “Saya sudah memilih solusi ini, masa harus ganti?” → DECISION.GOAL_DISCIPLINE.
3. “Kalau saya berhenti berarti saya gagal?” → GOAL_DISCIPLINE + SELF.PERSISTENCE + STRAT.ADAPTATION.
4. “Bagaimana tetap konsisten ketika metode harus berubah?” → SELF.CONSISTENCY + STRAT.ADAPTATION.
5. “Saya tidak yakin berita ini benar.” → LITERACY.DISCIPLINE.
6. “Saya sudah riset banyak, tapi tidak kunjung memutuskan.” → LITERACY.DISCIPLINE + DECISION.TRADEOFF.
7. “Saya gagal menjalankan rencana; apakah saya tidak disiplin?” → SELF.DISCIPLINE + DECISION.REVIEW, without moral diagnosis.
