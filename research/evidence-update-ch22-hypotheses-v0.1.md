# Evidence Update — Chapter 22: Jangan Jatuh Cinta pada Solusi Pertama

## Evidence focus

Chapter 22 addresses premature closure: committing to a solution before adequately testing the problem representation, alternatives, assumptions, or evidence. The goal is not endless analysis, but disciplined flexibility.

### 1. Premature closure can narrow the decision space

Once a preferred solution becomes psychologically salient, subsequent information may be interpreted through it. Decision-making research on confirmation, anchoring, escalation, and motivated reasoning provides relevant mechanisms, but the book should not collapse them into one universal cognitive bias.

### 2. Generate alternatives before evaluating one solution

Decision-analysis and problem-solving literature generally supports considering multiple options rather than evaluating a single proposed solution in isolation. The number of alternatives should remain proportionate to the stakes; more options are not automatically better.

### 3. Hypotheses are not guesses to defend

A useful hypothesis specifies what is expected if an explanation is correct and what evidence could weaken it. This preserves the distinction from advocacy.

### 4. Disconfirming evidence is especially important

Leaders should actively ask:
- What would make this solution wrong?
- What evidence would change my mind?
- What alternative explanation fits the same observation?
- What would we expect to see if the proposed cause were not present?

This connects Chapter 22 to Chapter 7's literacy discipline and Chapter 21's problem framing.

### 5. Small tests can be better than large commitments

Where feasible, pilot, simulation, staged rollout, reversible decision, or limited-scope experiment can provide information before a high-cost commitment. This is context-dependent and not possible for every decision.

### 6. Solution attachment can become goal substitution

A leader may start with:
> “We need to solve the problem.”

and later unconsciously defend:
> “We need to make this solution work.”

Chapter 22 should explicitly distinguish commitment to the goal from attachment to a particular method.

## Editorial implications

- Do not demonize intuition or expertise.
- Do not require exhaustive alternatives for every trivial decision.
- Do not equate disagreement with disconfirmation.
- Do not manufacture alternatives merely to appear analytical.
- Preserve the right to decide with incomplete information.
- Prefer reversible/low-cost tests when appropriate.
- State what evidence would change the decision.
- Separate evidence for the problem from evidence for the solution.
- Review sunk-cost pressure before extending a failing solution.

## Proposed book synthesis

**Frame → Hypothesize → Generate → Falsify/Stress-test → Test → Update → Commit**

This is a book working model, not a validated decision-making taxonomy.
