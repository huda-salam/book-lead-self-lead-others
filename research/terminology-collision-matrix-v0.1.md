## Canonical ownership rule

Each cluster has one primary owner. Other chapters may apply, compare, or qualify the concept but must link back to the canonical owner rather than silently redefine it.

## Retrieval QA questions

1. If a user asks “Apakah rendah hati berarti harus mengalah?”, does retrieval distinguish humility from passivity?
2. If a user asks “Saya mendengarkan berarti saya setuju?”, does retrieval distinguish listening from agreement?
3. If a user asks “Dia memengaruhi saya, berarti dia manipulatif?”, does retrieval request evidence before applying the manipulation label?
4. If a user asks “Saya gigih, mengapa harus mengubah cara?”, does retrieval surface adaptation?
5. If a user asks “Strategi saya apa?”, does retrieval distinguish strategic choice from action planning?
6. If a user asks “Tokoh ini berhasil, apakah caranya terbukti?”, does retrieval route through case reasoning and evidence?
